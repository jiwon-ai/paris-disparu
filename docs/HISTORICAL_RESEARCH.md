# Historical research

Status labels:

- **Verified** — confirmed in a source listed here, which has actually been read.
- **Widely reported** — stated by several secondary sources; primary source still to be checked.
- **Reconstruction** — plausible invention for gameplay, not a historical claim.
- **Fiction** — invented characters and events.
- **To research** — unverified.

At this stage **no claim is marked Verified**: the primary archives named in
the project brief (BnF/Gallica, Archives de Paris, INA, Carnavalet, RATP) have
not yet been consulted.
