- Author: Lee Minseo (quiple). Copyright (c) 2019-2025. Licence: OFL-1.1, full
  text in `LICENSE.txt` (no Reserved Font Name is declared).
- Source: npm package `galmuri` 2.40.3 (https://registry.npmjs.org/galmuri/-/galmuri-2.40.3.tgz),
  project https://github.com/quiple/galmuri. Files copied unchanged: `Galmuri11.bdf`, `Galmuri7.bdf`.
- Use in the game (Korean option only): `tools/ko_gen.py` converts the glyphs the
  Korean text needs into Game Boy tile data. Galmuri11 is the dialogue font,
  Galmuri7 (8x8, one tile per syllable) is the font of menus and the notebook.
- The package describes Galmuri as "based on the font design from Nintendo DS".
  Jiwon chose this font on 2026-11-24 (docs/DECISIONS.md); this note is kept so a
  legal review can see it.
